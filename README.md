# Tic-Tac-Toe AI - CodSoft Internship Task 2

A robust and unbeatable Tic-Tac-Toe game implemented in Python. This project utilizes the **Minimax algorithm** with a functional programming approach, emphasizing recursive decision-making and optimal game-state traversal.

## Features
- **Functional Architecture:** Implemented using a clean, non-object-oriented structure that isolates game logic, win-condition checking, and decision-making into modular helper functions.
- **Unbeatable AI:** Employs the Minimax algorithm to simulate every possible game state, ensuring the AI plays optimally to either win or force a draw.
- **Recursive Backtracking:** Uses depth-first search to evaluate moves, demonstrating a strong grasp of algorithmic complexity and game theory.
